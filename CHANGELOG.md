# Changelog

## Unreleased

- **Window back (C0):** new package `fs-calendars-simple`, the standard frontend. Calendars on the left (all, Private, Work, Family, Holidays), a large title with the shown range, Previous / Today / Next, the choice Month | Week | Day | Agenda, and the view of `calendar-view` from fs-components v0.0.24 (time axis, lanes for overlapping items, all-day bar, today and now marked). German and English (MessageFormat 2). The window shows **example data marked once as a preview** (`mode(capabilities)` drops them when the server offers `appointments`); every menu entry is locked "coming soon". Start page and "What comes". Headless pictures with `--picture`.
- **Starter:** `fs-calendars` and `fs-calendars app` open the frontend `fs-calendars-simple` next to the program and pass the words and the exit code on (before: "not available", exit 2). A missing frontend is said in German and English, exit 1. The starter starts no server: none speaks appointments yet.
- **Not in this version:** real appointments in the window, create and change, series dialog, calendar tick boxes, mini calendar, keys; see DESIGN, "Window `fs-calendars-simple`".
