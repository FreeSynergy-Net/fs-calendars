## 0.0.5

- **Window back (C0):** new package `fs-calendars-simple`, the standard frontend. Calendars on the left (all, Private, Work, Family, Holidays), a large title with the shown range, Previous / Today / Next, the choice Month | Week | Day | Agenda, and the view of `calendar-view` from fs-components v0.0.28 (time axis, lanes for overlapping items, all-day bar, today and now marked). German and English (MessageFormat 2). The window shows **example data marked once as a preview** (`mode(capabilities)` drops them when the server offers `appointments`); every menu entry is locked "coming soon". A context menu (right click, menu key, Shift+F10): New appointment here, Edit and Delete locked with their reason, Today. Start page and "What comes". Headless pictures with `--picture`.
- **Starter:** `fs-calendars` and `fs-calendars app` open the frontend `fs-calendars-simple` next to the program and pass the words and the exit code on (before: "not available", exit 2). A missing frontend is said in German and English, exit 1. The starter starts no server: none speaks appointments yet.
- **Lock (A4):** `check_lock_sources` strict is red (four libraries with two sources; each binary links exactly one `fs-types` source); the V1+ lift of the core is the next run, before the next calendars release; no `.fs-lock-sources.toml` with `strict = true` until then. / Auf Deutsch: `check_lock_sources` strict ist rot (vier Bibliotheken mit zwei Quellen; jedes Binary linkt genau eine `fs-types`-Quelle); der V1+-Lift des Kerns ist der nächste Lauf, vor dem nächsten calendars-Release; bis dahin keine `.fs-lock-sources.toml` mit `strict = true`.
- **Look:** a legend line with a dot in the calendar colour for each calendar (the navigation list of the shell cannot colour a dot); Previous/Next as arrows, Today as text, light buttons. / Auf Deutsch: Legendenzeile mit Punkt in der Kalenderfarbe je Kalender (die Navigationsliste der Shell kann keinen Punkt färben); Zurück/Vor als Pfeile, Heute als Text, helle Knöpfe.
- **Not in this version:** real appointments in the window, create and change, series dialog, calendar tick boxes, mini calendar, keys; see DESIGN, "Window `fs-calendars-simple`".
- Auf Deutsch: **Fenster zurueck (C0):** neues Paket `fs-calendars-simple`, das Standard-Frontend. Kalender links (Alle, Privat, Arbeit, Familie, Feiertage), grosser Titel mit dem gezeigten Zeitraum, Zurueck / Heute / Vor, Auswahl Monat | Woche | Tag | Terminuebersicht und die Ansicht `calendar-view` aus fs-components v0.0.28 (Zeitachse, Spuren fuer ueberlappende Termine, Ganztagsleiste, heute und jetzt markiert). Deutsch und Englisch (MessageFormat 2). Das Fenster zeigt **Beispieldaten, einmal als Vorschau markiert** (`mode(capabilities)` blendet sie aus, sobald der Server `appointments` anbietet); jeder Menuepunkt ist gesperrt "kommt noch". Ein Kontextmenue (Rechtsklick, Menuetaste, Umschalt+F10): Neuer Termin hier, Bearbeiten und Loeschen gesperrt mit Grund, Zu heute. Startseite und "Was kommt". Bilder ohne Fenster mit `--picture`.
- Auf Deutsch: **Starter:** `fs-calendars` und `fs-calendars app` oeffnen das Frontend `fs-calendars-simple` neben dem Programm und reichen Woerter und Exit-Code durch (vorher: "nicht verfuegbar", Exit 2). Ein fehlendes Frontend wird deutsch und englisch gesagt, Exit 1. Der Starter startet keinen Server: keiner spricht bisher Termine.
- Auf Deutsch: **Nicht in dieser Version:** echte Termine im Fenster, Anlegen und Aendern, Serien-Dialog, Haekchen je Kalender, Minikalender, Tasten; siehe DESIGN, "Window `fs-calendars-simple`".
